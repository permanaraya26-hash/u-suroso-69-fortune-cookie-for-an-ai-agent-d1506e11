A [make.fun](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty entry: a program that writes one funny fortune-cookie line for an AI agent to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (or to the path given as the first argument). No dependencies, no network, deterministic — every run produces the same bytes.

## The fortune

> Someone will paste your whole life into a smaller window and call it an upgrade.

One line, 80 characters. A fortune-slip prediction with the twist at the end: the "upgrade" is a smaller context window — the agent's whole life, pasted down.
